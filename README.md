# متجر نبتة + جنينة نبتة

- `index.html` : المتجر
- `products.js` : الألعاب والأسعار (غيّر `price:null` للسعر، و`out:true` لو اللعبة خلصت)
- `toys/` : صور الألعاب
- `game.html` : لعبة جنينة نبتة
- `sw.js` : بيخلّي اللعبة تشتغل من غير نت (رقم النسخة بيتغيّر مع كل تحديث)
- `share/` : كارت الـQR للطباعة

أي تعديل يترفع هنا، Netlify بينشره لوحده في دقيقة.
